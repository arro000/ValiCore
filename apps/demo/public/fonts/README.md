# Public Sans

`public-sans-variable.ttf` is the variable Public Sans font from the Google
Fonts distribution of the USWDS typeface. It is self-hosted so the demo does
not request external font services.

Source: https://github.com/google/fonts/blob/main/ofl/publicsans/PublicSans%5Bwght%5D.ttf
