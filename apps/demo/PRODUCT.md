# ValiCore demo

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

The front page serves anyone calculating or decoding an Italian fiscal code.
A dedicated integration section serves developers evaluating the library.
This hierarchy was explicitly selected by the user.

## Product Purpose

Make direct and inverse fiscal-code calculation immediately usable; make the
library's capabilities inspectable and its JavaScript/TypeScript integration
examples easy to copy.

## Capabilities and Constraints

The beta exposes fiscal identity and geographic history, not postponed domains.
The existing Rust/WASM engine owns calculations and official-catalog queries.
Keep historical birthplace selectors, validation levels, century ambiguity,
omocodia, source/version evidence and root/repository-prefix deployment working.
JavaScript and TypeScript are the currently supported wrapper examples.
All interface text and documentation remain in English.
Local validation does not confirm tax-registry allocation. Name fragments and
two year digits cannot establish full names or a birth century.

## Brand Commitments

Use Impeccable's design workflow. The user requested a front-page hero with
direct/inverse fields and a preview inspired by an Italian health card, plus
an integration button leading to playground and documentation. The preview is
a demonstration, not an official document or health-service credential.

## Evidence on Hand

Working calculation/decoding/place-selector forms, ANPR/ISTAT reconciled data,
the public wrapper types, extensive fixtures, and Playwright integration tests.
No invented language wrappers, credentials, registry checks or official seals.
