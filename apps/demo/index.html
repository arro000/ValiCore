Quick start

Initialize once with await createValiCore(). Reuse the engine for synchronous calls. Dates are Gregorian YYYY-MM-DD strings, with no timezone conversion.

Use birthplace: { name: 'Roma', province: 'RM' }, a Belfiore code, or an ISTAT code. Generation resolves the place against the birth date.

Validation & inverse results

valid can be true, false or null (indeterminate). Levels are structural, checksum, calendar and territorial. Inspect each check, rather than treating missing catalog data as invalid allocation.

Decoding cannot recover full names. A year range narrows date candidates; returned place records preserve history rather than selecting a current province.

Runtime, data & offline use

online uses compatible versioned runtime/data releases with cache and optional fallback. bundled works offline; pinned fixes a manifest; custom accepts your runtime and dataset.

Call versionInfo() and datasetInfo() to inspect versions, origins and coverage.

Place selector lifecycle

Import attachPlaceSelector from the /ui entry point. It supports native inputs and province selects. Call refresh() after programmatic changes and dispose() when removing the fields.
