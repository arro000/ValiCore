first, integration playground and documentation second. Code-led; no image
generation tool is available. Existing form behaviour and IDs are preserved.

preview is the result, not a promotional illustration above the tool.

OWN-WORLD: Public-service clarity: self-hosted Public Sans, ink blue on pale
blue/white surfaces, teal actions, small consistent corners. A flat pale-blue

Choose a feature to try it. Integration leads to JS/TS examples and API docs.

then calculate/decode tabs above two columns: personal fields left, card and
output right. Narrow widths stack without shrinking input text.
